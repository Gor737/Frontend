# Nelagram

Nelagram is a modern social networking web application where users can create accounts, manage their profiles, interact with other users, and communicate through private chats.

## Features

- User registration and authentication
- Protected routes
- User profile
- Profile avatar upload
- Bio editing
- Account privacy settings
- Password change
- User search
- User profiles
- Private messaging
- Real-time communication
- Responsive and modern UI

## Tech Stack

### Frontend

- React
- TypeScript
- React Router
- Axios
- React Hook Form
- Lucide React
- CSS

### Backend

- Node.js
- Express.js
- Sequelize
- PostgreSQL
- JWT
- Socket.IO
- Swagger / OpenAPI
